RGBLED·GPIOZERO
RASPBERRY PI · REV A

Four gpiozero programs for a common-cathode RGB LED, ordered from a single blinking output to a sentiment-driven mood lamp. Wiring is identical across all four — only the logic changes.

Wiring reference

Red channelGPIO 17
Green channelGPIO 27
Blue channelGPIO 22
Common cathodeGND

All four programs below reuse this exact circuit. Each leg runs through its own current-limiting resistor. Only the code deciding what color to show ever changes.

01
blink.py
Complexity: single output · one LED, on/off
▸

The starting point. A single LED on GPIO 17 turns on for a second, off for a second, forever. No color mixing yet — this is the loop, the try/finally cleanup pattern, and the GPIO pin, established once so the rest of the series can build on it.

from gpiozero import LED
from time import sleep

red = LED(17)

try:
    while True:
        red.on()
        sleep(1)
        red.off()
        sleep(1)
except KeyboardInterrupt:
    red.off()
    red.close()
    print("Program stopped safely.")
02
color_cycle.py
Complexity: sequence · stepping through a fixed palette
▸

Now all three channels are used together. An RGBLED steps through seven hard-coded (R, G, B) tuples — red, orange, yellow, green, blue, purple, white — holding each for half a second before moving to the next.

from gpiozero import RGBLED
from time import sleep

led = RGBLED(red=17, green=27, blue=22)

colors = [
    (1, 0, 0), (1, 0.5, 0), (1, 1, 0),
    (0, 1, 0), (0, 0, 1), (0.5, 0, 1), (1, 1, 1)
]

try:
    while True:
        for color in colors:
            led.color = color
            sleep(0.5)
except KeyboardInterrupt:
    led.off()
    led.close()
    print("Stopped")
03
fade.py
Complexity: transition · interpolating between fixed colors
▸

Rather than jumping between colors, this ramps one channel down while another ramps up, in 100 small steps with a 20 ms delay — blue → red, red → green, green → blue, repeating. The result reads as a continuous fade instead of discrete steps.

from gpiozero import RGBLED
from time import sleep

led = RGBLED(red=17, green=27, blue=22)

try:
    while True:
        for i in range(100):
            led.color = (i / 100, 0, 1 - i / 100)
            sleep(0.02)
        for i in range(100):
            led.color = (1 - i / 100, i / 100, 0)
            sleep(0.02)
        for i in range(100):
            led.color = (0, 1 - i / 100, i / 100)
            sleep(0.02)
except KeyboardInterrupt:
    led.off()
    led.close()
    print("Program stopped.")
04
ai_mood_lamp.py
Complexity: intelligent · color driven by sentiment analysis
▸

The color is no longer scripted — it's a response. Typed text is scored by VADER's SentimentIntensityAnalyzer; a compound score ≥ 0.4 turns the LED green, ≤ -0.4 turns it red, and anything in between stays blue.

from gpiozero import RGBLED
from time import sleep
from vaderSentiment.vaderSentiment import SentimentIntensityAnalyzer

led = RGBLED(red=17, green=27, blue=22)
analyzer = SentimentIntensityAnalyzer()

def set_color_from_sentiment(text):
    scores = analyzer.polarity_scores(text)
    compound = scores["compound"]

    if compound >= 0.4:
        led.color = (0, 1, 0)      # Green
    elif compound <= -0.4:
        led.color = (1, 0, 0)      # Red
    else:
        led.color = (0, 0, 1)      # Blue

try:
    while True:
        text = input("Type a sentence (or 'quit' to exit): ")
        if text.lower() == "quit":
            break
        set_color_from_sentiment(text)
        sleep(0.5)
except KeyboardInterrupt:
    print("Stopped by user.")
finally:
    led.off()
    led.close()
